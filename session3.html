Question 1:

What is HTML, and why is it important for websites?

Answer:

HTML stands for HyperText Markup Language. It is used to create and structure web pages.

Question 2:

What are the three main parts of an HTML tag?

Answer:

The three main parts are:
  1. Opening Tag
  2. Content
  3. Closing Tag

Question 3:

What is the purpose of HTML attributes, and where are they written?

Answer:

HTML attributes provide extra information about HTML elements. They are written inside the opening tag.

Question 4:

What are HTML comments used for? Are they displayed in a browser?

Answer:

HTML comments are used to add notes in the code. They are not displayed in the browser.

WRITE THE HTML TAGS

  • Heading (h1-h6)
  • Paragraph....(p)(/p)
  • Bold text....(b)(/b)
  • Italic text....(i)(/i)
  • Underlined text....(u)(/u)
