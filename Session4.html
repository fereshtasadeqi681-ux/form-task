ANSWER THE FOLLOWING QUESTIONS

Question 1:

What is an HTML boilerplate, and why is it used?

Answer:

An HTML boilerplate is a basic HTML structure. It is used as a starting point for creating web pages.

Question 2:

What is the purpose of the <!DOCTYPE html> declaration?

Answer:

The <!DOCTYPE html> declaration tells the browser that the document uses HTML5.

Question 3:

What is the difference between encoding and decoding?

Answer:

Encoding is the process of converting information into a specific format. Decoding is the process of converting it back into its original form.

Question 4:

What is metadata, and where are <meta> tags placed?

Answer:

Metadata is information about a web page. Meta tags are placed inside the <head> section.

Question 5:

What does charset="UTF-8" tell the browser?

Answer:

charset="UTF-8" tells the browser which character encoding to use. It supports many languages and special characters.

My HTML Boilerplate Page

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>WFE</title>
    <meta name="description"
    content="My first web design page.">
</head>
<body>
    <h1>Fereshta Sadeqi</h1>
</body>
</html>
